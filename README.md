# 📒 Quản Lý Danh Bạ - Python ✅

## 1. Tên dự án
**Quản Lý Danh Bạ - Python**

## 2. Ứng dụng dự án
Đây là ứng dụng quản lý danh bạ chạy trên **terminal**, cho phép người dùng thêm, xóa, sửa, tìm kiếm và thống kê các liên hệ của mình một cách dễ dàng.

### Tính năng chính
- 📋 Xem toàn bộ danh bạ
- ➕ Thêm liên hệ mới (tên, SĐT, email, nhóm)
- 🔍 Tìm kiếm theo tên (không phân biệt hoa/thường)
- ➖ Xóa liên hệ
- ✏️ Sửa số điện thoại
- 📊 Thống kê tổng số liên hệ và theo nhóm

### 🎬 Demo
```
Hãy lựa chọn phương án của bạn
    1. Xem toàn bộ danh bạ
    2. Thêm liên hệ
    3. Tìm kiếm theo tên
    4. Xóa liên hệ
    5. Sửa số điện thoại
    6. Thống kê
    7. Thoát

- Nhập lựa chọn của bạn: 6
- Tổng số liên hệ là 5
- Thống kê theo nhóm:
- Gia đình: 2 liên hệ
- Bạn bè: 2 liên hệ
- Công việc: 1 liên hệ
```

## 3. Công nghệ
- **Ngôn ngữ:** Python 3.x
- **Giao diện:** Command Line Interface (CLI)
- **Kiến thức áp dụng:**
  - `List` — lưu toàn bộ danh bạ
  - `Dict` — lưu thông tin từng liên hệ
  - `Set` — lấy danh sách nhóm duy nhất
  - `while True` + `break` — vòng lặp menu
  - `for` + biến cờ — tìm kiếm, xóa, sửa

## 4. Hướng dẫn sử dụng

### Yêu cầu
- Đã cài đặt **Python 3.x** trên máy

### Các bước chạy chương trình
1. Mở terminal tại thư mục chứa project
2. Chạy lệnh:
   ```bash
   python main.py
   ```
3. Chọn chức năng theo menu hiển thị (1–7) để xem, thêm, tìm kiếm, xóa, sửa liên hệ hoặc xem thống kê
